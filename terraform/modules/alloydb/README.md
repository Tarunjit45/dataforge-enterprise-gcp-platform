# AlloyDB for PostgreSQL Terraform Module

Provisions highly available AlloyDB for PostgreSQL cluster, primary read/write instance, secondary read pool instance, automated weekly backups, and private VPC network peering.

## Features
* **PostgreSQL Modernization**: Modernized target operational database replacing legacy MySQL.
* **High Availability**: Multi-zone Primary instance with secondary HA Read Pool instance.
* **Automated Backups**: Configured weekly automated backups with 4-week retention policy.
