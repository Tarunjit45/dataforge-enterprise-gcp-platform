# Operational & Executive Cloud Monitoring Dashboard Guide

This guide describes the 6 production Cloud Monitoring dashboards generated by `DashboardGenerator`.

---

## 📊 1. Executive Dashboard (`Executive Dashboard`)
Designed for C-level executives and engineering directors.
- **Widgets**:
  - `Platform Availability SLO (%)`: Tracks 99.9% target availability.
  - `Data Freshness SLA (Minutes)`: Tracks data arrival SLA (< 60 mins).
  - `Total Records Ingested & Cleansed`: Volume chart of processed data.
  - `Estimated Monthly Spend (USD)`: Total estimated GCP cloud spend.

---

## 🛠 2. Operations Dashboard (`Operations Dashboard`)
Designed for SREs and On-Call Engineers.
- **Widgets**:
  - `Active System Health Status`: GCS, Dataproc, BigQuery, AlloyDB, Datastream status.
  - `Pipeline Execution Failures`: Incident count chart.
  - `Active Alert Policies Fired`: Fired alert scorecard.

---

## ⚡ 3. ETL Dashboard (`ETL Dashboard`)
Designed for Data Engineers.
- **Widgets**:
  - `ETL Batch Execution Duration`: Histogram of batch processing time.
  - `Data Quality Score Trend (%)`: Batch quality score trends.
  - `Quarantine Record Volumes`: Count of records isolated in quarantine storage.

---

## 🔄 4. Migration Dashboard (`Migration Dashboard`)
Designed for Database Administrators and Migration Engineers.
- **Widgets**:
  - `Datastream CDC Replication Lag (Seconds)`: Real-time CDC lag monitor.
  - `Migrated Tables Progress`: Count of tables migrated and validated on AlloyDB.

---

## 🏗 5. Infrastructure Dashboard (`Infrastructure Dashboard`)
Designed for Cloud Infrastructure Architects.
- **Widgets**:
  - `Dataproc CPU & Memory Utilization`: Worker node resource usage.
  - `BigQuery Slots Consumed`: Concurrent slot allocation trends.

---

## 💰 6. Cost Dashboard (`Cost Dashboard`)
Designed for FinOps and Cost Management Teams.
- **Widgets**:
  - `Daily Spend by Service`: Stacked bar chart (BigQuery, Dataproc, GCS, AlloyDB).
  - `BigQuery Bytes Scanned vs Slot Usage`: Query scan efficiency.
