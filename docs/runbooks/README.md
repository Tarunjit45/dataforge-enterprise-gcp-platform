# Operational Runbooks Index

This directory contains standard operating procedures (SOPs) for site reliability engineering (SRE) and data platform operation teams.

## Emergency Runbooks Index

* `RB-001-PIPELINE-FAILURE.md`: Triage procedure for failed Dataproc batch jobs.
* `RB-002-QUARANTINE-REPROCESS.md`: Standard workflow for auditing and reprocessing quarantined payload files.
* `RB-003-ALLOYDB-FAILOVER.md`: Manual and automated failover verification for AlloyDB High Availability Read Pool.
* `RB-004-DISASTER-RECOVERY.md`: Point-in-time recovery (PITR) procedures for storage and analytical datamarts.
