# Platform Cost & Performance Optimization Guide

This guide details cost and performance optimization recommendations generated by `OptimizationEngine`.

---

## 💰 1. High-Impact Optimization Recommendations

1. **Partition Filter Enforcement**:
   - Enforce `require_partition_filter=true` on BigQuery `fact_trip` table.
   - **Impact**: Eliminates full-table scans; reduces query cost by up to **30%**.

2. **Dimension Clustering**:
   - Cluster `fact_trip` by `vendor_key`, `payment_type_key`, `pickup_location_key`, `rate_code_key`.
   - **Impact**: Speeds up filtered JOIN queries; reduces byte scanning by **40%**.

3. **Preemptible / Spot VMs**:
   - Configure secondary Dataproc worker nodes to use Preemptible/Spot VMs.
   - **Impact**: Reduces Dataproc compute cost by up to **60%**.

4. **GCS Lifecycle Rules**:
   - Transition `raw_bronze` objects to Nearline storage after 30 days and Coldline after 90 days.
   - **Impact**: Reduces long-term GCS storage costs by **50%**.

5. **BigQuery Materialized Views**:
   - Leverage `mv_executive_summary_mart` and `mv_geographic_demand_mart` for BI dashboards.
   - **Impact**: Cuts BI dashboard query latency by **80%**.
